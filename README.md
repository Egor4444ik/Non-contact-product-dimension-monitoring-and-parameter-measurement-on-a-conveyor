# Проект сегментации 3D-объектов на конвейере

Проект предназначен для выделения объектов интереса из облаков точек, полученных камерой глубины, моделирования их перемещения на конвейерной ленте и обучения нейросетевой модели (RGCNN) для сегментации объектов с последующим расчётом их геометрических размеров.

---

## Структура проекта

```
├── InterestingObjectDetection.py   # выделение объектов интереса из последовательности кадров
├── ObjectEditing.py                # манипуляции с облаками точек (поворот, масштабирование, перенос)
├── TransportationSim.py            # анимация перемещения чайника вдоль конвейера
├── visualizeObject.py              # утилиты визуализации, загрузки, поворота, вычисления объёма
├── ML/
│   ├── Dataset.py                  # аугментации, генерация синтетических данных, класс датасета
│   ├── Model.py                    # реализация RGCNN (графовые свёртки Чебышёва)
│   ├── Train.py                    # скрипт обучения модели
│   ├── UseModel.py                 # загрузка модели и предсказание на новых облаках
│   └── utils/
│       └── Metrix.py               # вычисление IoU и оценка модели
├── backend/utils/config.py         # конфигурационные пути (OBJECTS_OF_INTEREST_FOLDER и др.)
```

## Основные компоненты

### 1. Выделение объектов интереса (`InterestingObjectDetection.py`)

- Класс `ObjectExtraction` загружает последовательность кадров (облаков точек) из папки `PRODUCTION_DATA`.
- Анализирует изменение количества точек по кадрам, находит локальные минимумы и максимумы, выделяет разностные кадры – точки, появившиеся между минимумом и максимумом (объекты).
- Сохраняет полученные объекты в папку `OBJECTS_OF_INTEREST_FOLDER` (по умолчанию `diff_frames/`).

**Использование:**
```python
from InterestingObjectDetection import ObjectExtraction
obj = ObjectExtraction()
obj.frame_extacter()
obj.save_frames()
obj.visualize_dif_obj()
```

### 2. Редактирование облаков (`ObjectEditing.py`)

- Класс `MultyDimentionObject` загружает точки из `.txt`, позволяет поворачивать, масштабировать, сдвигать и перемещать центроид объекта.
- Методы возвращают `self`, что позволяет строить цепочки преобразований.

### 3. Симуляция конвейера (`TransportationSim.py`)

- Класс `Simulation` создаёт 3D-анимацию движения чайника (`teapot.txt`) вдоль конвейерной ленты (`ConveyorBeltAssemblyLine.txt`).
- Поддерживает сохранение каждого кадра в виде текстового файла (облако точек конвейера + чайник).
- Используется для генерации синтетических обучающих данных (если нужно).

**Использование:**
```python
sim = Simulation(conveyor_point_step=20, teapot_point_step=10)
sim.run()                     # запуск анимации
sim.save_frames("frames/")    # сохранение кадров
```

### 4. Визуализация и утилиты (`visualizeObject.py`)

- Функции загрузки/сохранения точек, поворота, вычисления выпуклой оболочки и объёма.
- Визуализация через `matplotlib` и `pyvista`.
- Функция `load_teapot` размещает чайник на указанной поверхности.

### 5. Датасет и аугментации (`ML/Dataset.py`)

- Генераторы синтетических форм: сфера, куб.
- Аугментации: случайный поворот, масштабирование, сдвиг, шум.
- Класс `PointCloudDataset`:
  - Загружает эталонный объект (из `.txt`).
  - На каждом запросе создаёт облако из **2048** точек, смешивая объект с фоном (шар/куб) с заданной вероятностью.
  - Возвращает тензоры: `(points, labels, category)`.

### 6. Модель RGCNN (`ML/Model.py`)

- **GetGraph** – строит матрицу смежности по евклидовым расстояниям (гауссово ядро).
- **GetLaplacian** – вычисляет нормализованную матрицу Лапласа.
- **GetFilter** – свёртка на графе с использованием полиномов Чебышёва порядка **K**.
- **RGCNN_Seg** – основная модель, принимает облако `(B, M, 3)` и категорию, возвращает логиты размерности `(B, M, num_classes)`.
- Параметры: `F` – число фильтров на слоях, `K` – порядки полиномов.

### 7. Обучение (`ML/Train.py`)

- Функция `train(input_3_dim_object_path)` загружает объект из `.txt`, создаёт датасеты (с аугментацией и без), инициализирует модель и обучает 50 эпох.
- Используется оптимизатор **Adam**, функция потерь **CrossEntropyLoss** с L2-регуляризацией.
- Каждые 30 шагов вычисляются метрики на валидации (loss, accuracy, mIoU) с помощью `evaluate_model`.
- Лучшая модель сохраняется как `best_model.pth`.

**Запуск обучения:**
```bash
python -m ML.Train
```
(предварительно укажите путь к файлу объекта в `train()`).

### 8. Применение модели (`ML/UseModel.py`)

- `load_model` загружает сохранённые веса.
- `predict_cloud` принимает облако точек, возвращает предсказанные метки (0 – фон, 1 – объект) и вероятности.
- В блоке `if __name__ == "__main__"` демонстрируется:
  - Генерация синтетического облака (90% объект, 10% фон).
  - Предсказание с порогом 0.85.
  - Вычисление габаритных размеров и объёма объекта (по осям X, Y, Z).
  - Визуализация результата (синие/красные точки) через `pyvista`.

### 9. Метрики (`ML/utils/Metrix.py`)

- `compute_iou(pred, target, num_classes)` – вычисляет IoU для каждого класса и средний IoU.
- `evaluate_model(model, dataloader, device, num_classes)` – полная оценка модели на даталоадере.

## Пример рабочего пайплайна

1. **Получение объектов интереса**  
   Поместите последовательность кадров (txt-файлы с координатами) в папку, указанную в `PRODUCTION_DATA`, и выполните:
   ```python
   from InterestingObjectDetection import ObjectExtraction
   obj = ObjectExtraction()
   obj.frame_extacter()
   obj.save_frames()   # объекты сохранятся в diff_frames/
   ```

2. **Обучение модели**  
   Укажите путь к одному из полученных файлов (например, `diff_frames/diff_frame_0000.txt`) в функции `train` и запустите:
   ```bash
   python -m ML.Train
   ```

3. **Использование модели для новых данных**  
   Загрузите модель и примените к облаку точек (из реальной съёмки или синтетическому):
   ```python
   from ML.UseModel import load_model, predict_cloud
   model = load_model("best_model.pth")
   points = np.loadtxt("my_cloud.txt")
   labels, selected_pts, probs = predict_cloud(model, points, prob_threshold=0.85)
   ```

4. **Анализ размеров** (встроен в `UseModel.py`) – если выделено >500 точек объекта, выводятся ширина, глубина, высота и объём в условных единицах.

## Примечания

- Все текстовые файлы с облаками точек должны содержать три координаты `x y z` на строку, разделённые пробелами.
- Файлы `teapot.txt` и `ConveyorBeltAssemblyLine.txt` должны находиться в корневой папке (или укажите полные пути в коде).
- Для использования GPU удостоверьтесь, что установлен `cudatoolkit` и версия PyTorch с поддержкой CUDA.
